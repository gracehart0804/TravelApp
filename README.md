# TravelApp

My app is a postcard and digital travel keepsake space. The user can add postcards for places they have traveled with a photo and a description. The postcards are linked to a 3D map with a pin where the location is to give you a whole visual outlook of the globe. The gallery view lets users upload photos from the places they have been to get an outlook of your whole trip. Under the profile screen, there are stamps like in a passport to get another visual element. Below that, there is the Bucket List that allows users to add places they want to travel to. By clicking on the bucket list locations they can be added to the map, postcards and passport stamps. This is also reversible if it was clicked on accident. By doing a long click on the bucket list, the user can edit the bucket list location they added. This feature is also available on the postcards screen, so users can edit their postcards. 
I used ChatGPT (and a little bit of Claude) to help me code the entire project, I prompted it in sections mostly for each screen. From there it was a lot of refinement with buttons and connecting the screens to each other. I did not use an API, just ChatGPT in curating a data set.
